There's a phrase people use when they want to dismiss something: *it's eating its own tail*. Circular. Self-referential. Unstable. The implication is that something propped up only by itself will eventually collapse.

They say it about AI now. That AI is only useful for building more AI. That it's speculation dressed as progress.

I don't think that's what's happening.

I think what's happening is a closed loop — and closed loops are not the same as circular reasoning. A steam engine burning coal to move ore to build better furnaces to smelt steel to build better steam engines is not eating its own tail. It's compounding. Each iteration produces something more capable than the last, and that capability feeds the next cycle.

Nvidia uses AI to design its next GPU architecture. That GPU runs faster. Which trains better models. Which design better chips. This isn't circular — it's a flywheel. Every revolution produces more torque than the last.

The steam engine didn't just replace horses. It shipped the parts to build railroads, which shipped the parts to build more engines, which reached more mines, which produced more coal. The loop closed in on itself and the whole system accelerated. The outside world didn't fully understand what had changed until the landscape was unrecognizable.

The difference between this and crypto, the thing people keep missing, is output. The steam engine loop produced physical movement. The railroad loop produced connected cities. The AI loop produces genuine capability — code that runs, research that advances, architectures that train faster. The value is not in believing the loop will produce something. The value is in what the loop is already producing.

We haven't seen a feedback loop this tight before. Not at this speed. The steam engine took decades to compound into railroads into industry. AI's loop is measured in months.

That's not a warning sign. That's just what it looks like when the loop finally closes.
